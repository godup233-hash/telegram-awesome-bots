## 🚀 30 秒上手指南

1. 打开 Telegram，点顶部搜索框
2. 输入机器人用户名（如 `@jisou`）
3. 点进机器人 → 点 **Start / 开始**
4. 直接发送关键词，秒出结果

**想找群？** 给 @jisou 发一个关键词（如"Python 学习"）→ 它会返回相关群组列表，点击即加入。

## ⚠️ 使用前必读（安全声明）

1. **机器人≠官方**：除 @BotFather 外，本仓库收录的均为第三方机器人，使用前自行判断风险。
