## 🚀 30 秒上手指南

1. 打开 Telegram，点顶部搜索框
2. 输入机器人用户名（如 `@jisou`）
3. 点进机器人 → 点 **Start / 开始**
4. 直接发送关键词，秒出结果

**想找群？** 给 @jisou 发一个关键词（如"Python 学习"）→ 它会返回相关群组列表，点击即加入。

## ⚠️ 使用前必读（安全声明）

1. **机器人≠官方**：除 @BotFather 外，本仓库收录的均为第三方机器人，使用前自行判断风险。
2. **不碰"社工库"类机器人**：任何声称"查个人信息、查开房记录"的机器人都是违法黑产，远离并举报。
3. **不扫陌生二维码、不点可疑链接**：部分搜索结果会夹带广告外链，点击前看清楚域名。
4. **下载类机器人注意版权**：资源下载仅供个人学习，请勿用于商业传播。
5. **代充/会员类机器人风险高**：涉及资金交易，概不建议，被骗无处申诉。
