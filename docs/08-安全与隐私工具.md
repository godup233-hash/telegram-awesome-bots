## 🥇 Dr.Web — [@DrWebBot](https://t.me/DrWebBot)

俄罗斯老牌杀毒厂商 Dr.Web 官方出品。

- 功能：发文件或链接给它 → 扫描病毒、木马、钓鱼；拉进群可自动检查群友分享的文件（个人版 20MB 上限）
- ✅ 多语言、有静默模式不刷屏
- 🎯 适合：资源群、经常接收陌生文件的用户

## 4️⃣~6️⃣ 辅助工具

- **@WatchDoorBot**：禁止群内发送指定类型消息，防恶意举报炸群

## 🚨 TG 防骗六条铁律

1. **"官方客服"主动私聊 = 骗子**。Telegram 官方从不私聊用户
2. **不扫任何二维码登录**，扫码 = 交出账号
3. **"查档/社工库"机器人 = 违法黑产**，使用即违法
4. **代充会员、低价 Premium**：十个九个骗，付钱就拉黑
5. **陌生人发的 .apk/.exe 文件**：先丢给 @DrWebBot 扫一遍
6. **开启两步验证**：设置 → 隐私与安全 → 两步验证，必开

## 🛡️ 账号安全自检清单

- [ ] 开启两步验证
- [ ] 手机号可见性设为"联系人"
- [ ] 检查"活动会话"踢掉陌生设备
- [ ] 群聊邀请权限设为"联系人"
- [ ] 不向任何机器人提供短信验证码
